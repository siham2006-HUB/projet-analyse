# Analyse des ventes Superstore

## Données

Télécharger le jeu sur https://www.kaggle.com/datasets/vivek468/superstore-dataset-final, extraire le zip et placer `Sample - Superstore.csv` dans `data/raw/`.

## Notebooks

À lancer dans l'ordre : `01_exploration`, `02_nettoyage`, `03_analyse`.

## Résultats principaux

- Ventes : +56 % entre 2015 et 2017, pics en fin d'année.
- Technology est la catégorie la plus rentable ; Furniture gagne très peu.
- Au-delà de 20 % de remise, les commandes sont à perte.
- West est la région qui vend le plus.
- Délai moyen d'expédition : 4 jours.
